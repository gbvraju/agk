# Vision

Teams adopting coding agents lose consistency: context is lost after compaction, scope creeps late in a feature,
tests get weakened to go green, and nobody reads the diff against the specification. agk makes the disciplined path
the easy path. It puts the rules where an agent cannot switch them off — committed settings and hooks, branch
protection, CI checks, a weekly drift audit — and gives engineers the method that makes agents produce reviewable,
traceable work: requirements with acceptance criteria, specifications with approval states, decision records,
reviewer groups with path-class authority, briefs, and residual registers with dates. Agents implement; people
decide; the repository proves it. Claude Code only, GitHub first, open source, measured by review rejections per PR,
blocked check-weakening attempts, audit findings per week, spec deviations per feature and cost per merged PR.
Non-goals for v0: other agents or hosts; Jira/Linear; hosted services; UI.
