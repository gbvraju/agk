# Changelog

The changes to the kit of this repository, newest first. In flow mode a build pull request adds one line under `## Unreleased`; a release pull request moves the lines under the new version (SPEC-0028). The history before 0.54.0 is in the git log and in `docs/runs/`.

## Unreleased

## 0.64.4 (2026-11-14)

- #1249 `agk doctor` reports, as `misplaced-settings`, a setting that the kit reads from a table of `agk.toml` (`[flow]`, `[testing]`, `[capacity]`, `[plan]`, `[design]`, `[delivery]`) but that stands at the top level or in another table, naming the key and both tables, never its value; the template's flow block says the keys belong in the `[flow]` table (brief #1245, ADR-0527)
- #1250 A fresh reviewer gives every gating verdict, in local mode too: `[flow] reviewer_slots` puts reviewer slots at the gate, `conductor.py review --pr N [--start]` asks one and in local mode starts it through the launch adapter, `check-verdict` keeps the conductor's own verdict to a timed `(conductor fallback)`, and the review guard lets a slot save its bundle in its scratch folder (brief #1248, ADR-0528)
- #1255 The stop hook runs only the governance checks a session's own changes need: none when nothing changed, the checks that read the changed documentation or configuration files, and the full set for any other path; `[flow] stop_check = "changed" | "full" | "off"` chooses the mode (`"off"` is refused in solo review mode), and each run prints one `stop check:` line (brief #1254, ADR-0531)
- #1260 Adapter-started builders run on the model their brief's kind needs: both launch adapters pass `--model "$AGK_MODEL"` (and `--effort` beside it) to `claude` when `[models.names]` names the tier, and no flag otherwise; `doctor.py` warns `model-names` when `auto_start` and `launch_adapter` are set without `[models.names]`, and the local-mode guide names the table (brief #1252, ADR-0530)
- #1261 `session.py plan` reads only what a pass needs: it judges the open briefs from their listing (a `Depends-on` brief no open listing holds is closed, no GET each), reads the comments of the briefs that pass in milestone order only until the free slots are filled, reads the open and recently closed pull requests instead of every pull request, and ends with `reads: <n> calls (<m> from cache), <s> s` (`reads` in `--json`, point 8 of `checklist.py`); `session.py claim` labels its brief `agk:taken` (brief #1251 build (a), ADR-0529 Proposed)
- #1265 In local mode the conductor's own governance run and the guarded merge's run call the kit's `make -f agk.mk agk-governance`, so a project set up with adopt, which may have no `governance` target in its Makefile, can be reviewed and merged; the old `make -C <scratch> test|governance` forms stay allowed (brief #1264, ADR-0535)
- #1268 In local mode the conductor moves the pull request labels on each review pass (`route.py --all`, allowed by its guard only in local mode), and the router decides local mode from `execution = "local"` or one search call instead of paging every open issue, reading the open pull requests once per run (brief #1263, ADR-0534)
