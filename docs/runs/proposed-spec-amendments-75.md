# Proposed spec amendments 75 (SPEC-0034, SPEC-0012; REQ-041)

Date: 2026-10-25 (from `date -u`). Approved specs change only through a proposal like this one (principle 6). Applied by ADR-0139. The paths: `docs/specs/0034-a-team-sets-how-many-builder-sessions-run-at-once-and-agk-ha.md` and `docs/specs/0012-intake.md`. The number 75 and ADR-0139 were reserved for this build on #176 by the conductor. It gathers the three follow-up items recorded on #176 after parallel builds took the same number.

1. **SPEC-0034 rule 4, the numbers of the intake check.** `intake.py check` (also `check --final`) takes an option `--ids FILE`: the file is the line `session.py ids` printed, and C1 takes the next free requirement, spec and ADR numbers from it, so that a number held by an open builder pull request or by a reservation is not read as free. Without the option the check keeps the default branch, as before; the check reads the file only, and `session.py` stays the only script that calls GitHub. A file that is not that output is refused naming the option and never its content.
2. **SPEC-0034 rule 4, the number of a session rule.** `session.py ids` also prints `rule`, the next free session-rule number, counted from the numbered lines of `config/session-rules.md` on the default branch and from the numbered lines that open builder pull requests add to it. `session.py ids --exclude-pr N` leaves the open pull request N out of the count, so that a session can check its own pull request against the numbers of the others.
3. **SPEC-0034 rule 7c, a number moved.** The mechanical conflicts of a session include a session rule number moved to the next free one, next to a number moved by `intake.py renumber`; `config/session-rules.md` rule 15 says so.
4. **SPEC-0012 rule 11, C2 and the decisions log.** C2 also allows `docs/runs/decisions-log.md` in an intake, with added rows only (no row changed or removed), so that the rulings of the questions of the intake are recorded before the spec flips. Any other file beyond the requirements file, one new spec and one new ADR still fails C2.
