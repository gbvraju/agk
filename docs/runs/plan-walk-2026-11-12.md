# Plan walk 2026-11-12: an invented prototype and one document to printed briefs

Recorded by brief #1079 (ADR-0460) for `docs/guides/planning.md`. Date from `date -u`. Everything here is invented: the
project "Order desk" of `example.com`, its three-screen prototype (four pages and one picture page) and its one product
requirements document. No customer file enters this repository, and nothing was sent to GitHub: `publish` printed its
commands and ran none.

How it was run: a script made the invented project in a temporary folder, with the kit's data guard
(`scripts/agk/guard.py`, `.claude/hooks/data_guard.py`), `config/reviewers.yaml` naming the invented account
`demo-owner` in `spec_approvers`, the spec template and an inventory of three screens (`sign-in`, `orders` and
`order-detail`; `orders` with the states `default`, `empty` and `error`, every other required state `n/a: <reason>`). It
ran each command with the kit's scripts at `origin/main` 7ffd070, from the project's root, and recorded the output
verbatim. Each command is shown as a project runs it (`$AGK` is the plugin root). The proposals file of step 5 is
written by hand as `/agk:plan-intake` would write it, so the walk needs no model.
