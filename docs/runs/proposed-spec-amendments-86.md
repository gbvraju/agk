# Proposed spec amendments 86 (SPEC-0004, SPEC-0010; REQ-039)

Date: 2026-10-26 (from `date -u`). Approved specs change only through a proposal like this one (principle 6). Applied by ADR-0151. The paths: `docs/specs/0004-drift-audit.md` and `docs/specs/0010-proof-checks.md`. The number 86 and ADR-0151 were reserved for this build on #204 by the conductor (brief #244, build (a)).

1. **SPEC-0010, new rule 26, `retired`.** The statuses of a requirement are `planned`, `in-progress`, `done` and `retired`. A requirement is retired with an ADR, like any change of a `done` one. While a requirement is `retired`, no test file under the test directories may carry its `REQ-nnn` marker: `check_requirements.py` fails naming the requirement and the files, never the test's text. The pull request that retires a requirement therefore removes its tests or retags them to a requirement they still prove. This is the one new block, and it falls only on that pull request. A retired requirement needs no marker and no criteria coverage.
2. **SPEC-0004, new rule 24, D8 untagged test files.** At the head of the default branch the audit adds one finding D8, subject `tests`, when test files (the directories and patterns the checks use for markers) carry no `REQ-nnn` marker. The sentence gives the count and the paths, up to 20, then `and N more`. It never blocks and names paths only, never content. A project with none gets no finding. Rule 11 reads `D1`..`D8`, and the summary line carries `D8=<n>`.
3. **Traceability.** `traceability.py` ends with `Retired: <ids>` and `Untagged test files (<n>): <paths>` when there are any, after a blank line, and is unchanged when there are none.
4. **The requirements file** (`docs/requirements.md`, `kit/templates/requirements.md`) names the four statuses in its first paragraph.
5. **The facts.** `drift.counts` of the facts document carries `D8` next to `D1`..`D7` (an optional property of schema 1: a document without it still validates), and the weekly report, which copies the drift counts, carries it too; the goldens of the facts and report fixtures change by that one count.
