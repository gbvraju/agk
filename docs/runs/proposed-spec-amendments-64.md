# Proposed spec amendments 64 (SPEC-0030, SPEC-0032, SPEC-0034; REQ-039)

Date: 2026-10-25 (from `date -u`). Approved specs change only through a proposal like this one (principle 6). Applied by ADR-0126. The paths: `docs/specs/0030-a-conductor-role-reviews-every-pull-request-posts-the-verdic.md`, `docs/specs/0032-github-events-label-each-pr-people-approve-specs-a-red-branch-stops-work.md`, `docs/specs/0034-a-team-sets-how-many-builder-sessions-run-at-once-and-agk-ha.md`. The number 64 is the one the conductor reserved for build (e1) on #179.

1. **SPEC-0034 rule 2, the `Priority:` line.** A brief may carry `Priority: 0` beside `1` to `3` (SPEC-0032 rule 9), but only with one line `Measured:` (item 2). The brief the router writes for a red default branch (`Advances: none`, `Priority: 0`, SPEC-0032 rule 7) is the one exception and carries none, because it names no cause. A hand-written `Priority: 0` brief is ordered by `session.py next` before `Priority: 1`, after the router's red-branch brief (the verdict on #206); only the router's issue, which `is_red` identifies by its author, its title and the `Priority: 0` line, is handed out alone and stops other sessions (SPEC-0032 rule 7).
2. **SPEC-0032 rule 9, the shape of the line.** A `Measured:` line holds, on one line, the command run and the output before and after a change that turns it green; the check reads that the line is not empty and holds the words `before` and `after`, and at most one such line is allowed in a brief. `check_brief.py` and `session.py next` apply it (the shape is `brief_problems`); the conductor role file forbids naming a cause without it; the builder reproduces the cause first (`config/session-rules.md` rule 13).
3. **SPEC-0032 rule 10 and SPEC-0030 rule 2, a correction ends `watch`.** `session.py watch --pr N` also exits 0 with one line, `correction #<n> (comment <id>): <first line>`, on a comment whose first line starts `Correction:` by a listed verdict author, newer than the start of the watch, on the pull request or on the brief named by the `Brief: #<n>` line of its body. A comment of an unlisted author, one that is not a correction, or one older than the start does not end it. `config/session-rules.md` rule 1 names the exception and rule 14 says what the builder does.
4. **SPEC-0032 rule 10, the conductor edits the brief.** The rule says the conductor edits the brief in place. The guard of the conductor role file allows only the comment POST (SPEC-0030 rule 6), so the role file says the brief's text is edited in place by the session that filed it or by a person, and that the Correction names the void lines. Changing the guard is not part of build (e1).
