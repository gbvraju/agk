# Proposed spec amendments 58 (SPEC-0009, SPEC-0022, SPEC-0024; REQ-040)

Date: 2026-10-25 (from `date -u`). Approved specs change only through a proposal like this one (principle 6). Applied by ADR-0121. The paths: `docs/specs/0009-facts.md`, `docs/specs/0022-the-weekly-product-report-also-publishes-the-sections-it-com.md`, `docs/specs/0024-the-report-s-cost-totals-carry-the-number-of-the-week-s-merg.md`.

1. **SPEC-0009, the facts of a pull request.** The pull-request record carries the optional `usage` (SPEC-0033 rule 8): the sum of the `Usage: <n> tokens` figures that end the first line of the `Report:` comments of the pull request's author, a whole number; `not-reported` when there is none (a figure of zero is a figure and stays `0`); `unknown` when the comments cannot be read. `facts.json` keeps schema number 1.
2. **SPEC-0022 and SPEC-0024, the cost lines.** The item `pull-request-cost` gains the field `usage` (a whole number, `not-reported` or `unknown`; facts without the field read `unknown`, because they cannot say that nothing was reported), and the item `week-totals` gains `usage` (the sum of the reported figures, `not-reported` when no merged pull request reported one, `unknown` when one could not be read) and `usage_reported` (how many merged pull requests reported one). The markdown prints `usage N tokens`, `usage not reported` or `usage unknown` on each cost line and `usage in total: ...` before the estimate on the totals line; a missing figure is never printed as zero. `report.json` takes schema number 5 and `kit/report-schema.json` requires it.
