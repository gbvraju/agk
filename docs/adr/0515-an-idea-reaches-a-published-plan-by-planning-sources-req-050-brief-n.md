# ADR-0515: An idea reaches a published plan by planning sources

- Status: Proposed
- Date: 2026-11-14
- Deciders: maintainers
- Related: SPEC-0043, SPEC-0037, SPEC-0013, ADR-0458, brief #1216, plan #661
- Requirements: REQ-050

## Context

A project that starts from a prototype reaches a published plan: `/agk:design import`, `design_import.py source`,
`/agk:plan-intake`, `publish` and `/agk:board`. A project that starts from an idea has its own early steps
(`/agk:start` or `/agk:vision`, `/agk:design inventory` and `/agk:design prototype` with a sign-off, `/agk:stack`), but
none of their files feeds `plan_intake.py`: `design_import.py source` accepts only an imported version (`i<n>`), no
command writes a `docs/sources/` file from the vision, the charter ADR or the stack ADR, and `docs/guides/planning.md`
describes only the prototype and OpenSpec paths. The owner asked (2026-11-14) that both paths reach the same plan.

## Decision

1. `scripts/agk/design_import.py source` also takes a kit version `v<n>` of `docs/design/prototype/`: it writes once
   `docs/sources/<slug>-prototype-v<n>.md`, header `Source: kit prototype v<n>`, `Kind: design`,
   `Version: v<n> <the version's sign-off digest>`, `Date:` (UTC), then one `## <screen>/<state>` heading per page
   `<screen>--<state>.html` of the version folder, in file-name order, with the page's visible text read as for an
   imported page. It refuses, writing nothing, a version that is not there, one that `design_signoff.signed_off` does
   not find signed off with the digest its folder has now, one with no such page, and an existing file. `components`
   still takes an imported version only.
2. A new installed script `scripts/agk/plan_sources.py` has two commands. `vision` writes once
   `docs/sources/vision.md` (`Kind: charter`, `Version: ADR-<n> <digest of the two files>`) holding
   `constitution/vision.md` and then the charter ADR `docs/adr/<n>-project-charter.md`, both unchanged, so every
   heading is kept. `architecture` writes once `docs/sources/architecture.md` (`Kind: other`) holding the stack ADR
   `docs/adr/<n>-stack-options.md` unchanged. The ADR read is the highest-numbered file of its name; each command
   refuses with exit 1, naming the rule and the file and writing nothing, an ADR that is not `Accepted`, a missing
   ADR or vision, and an existing target file; a malformed command exits 2 with the usage.
3. `docs/guides/planning.md` gains the section "From an idea", one numbered line per command from the vision to the
   board; the `start`, `vision`, `design` and `stack` skills each end by naming the next command of that path.
4. SPEC-0043 is not edited here: amendment 174 (`docs/runs/proposed-spec-amendments-174.md`) proposes rule 2a's
   extension and a rule 2b for the maintainers.

## Consequences

A greenfield project has a scripted path from its approved vision to `/agk:plan-intake`, `publish` and `/agk:board`,
and `plan_intake.py states` and `check_plan.py` read the three files as they read any source. Tests:
`tests/kit/test_plan_sources.py` (vision and architecture sources, the refusals, and the planning commands reading the
three sources) and `tests/kit/test_design_import_source.py` (a signed-off `v1` becomes a design source; an unsigned or
changed one is refused). Protected path classes changed: `scripts/agk/` (`design_import.py`, `plan_sources.py`),
`tests/kit/` (the tests), `skills/` (the `start`, `vision`, `design` and `stack` skills) and `kit/`
(`kit/manifest.json` lists the new script; `kit/hashes.json` regenerated by `kit_hashes.py`), and `agk.toml` (one
`[[testing.map]]` entry maps `plan_sources.py` to its tests). No workflow changes.

## Residual

- 2026-11-14: the vision source copies the vision and the charter as they are; a vision that still holds the
  template's placeholders is not refused here (`engines.py vision-check` refuses it before the charter merges). The
  maintainers may add that refusal (due 2026-12-31).
