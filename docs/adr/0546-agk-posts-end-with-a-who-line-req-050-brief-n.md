# ADR-0546: AGK's posts end with a light Who line

- Status: Proposed
- Date: 2026-11-14
- Deciders: maintainers
- Related: SPEC-0059, brief #1289, plan #661
- Requirements: REQ-050

## Context

The owner and every AGK session post as one GitHub login (SPEC-0059 Q-S0059-4), so a person reading the history of an
issue or a pull request cannot tell at a glance which lines AGK wrote and which the owner typed. The runtime's
`Generated by Claude Code` footer is added only to some posts, and it is a link, not a marker. The owner asked
(2026-11-15 00:17 to 00:19 IST, quoted in brief #1289) for a light marker that is part of how AGK posts and not a new
rule: `Who: AGK` on AGK's posts, `Who: ProductOwner` on a post that relays an owner decision, nothing on the owner's own.

## Decision

1. `scripts/agk/common.py` holds the marker: `with_who(body, who="AGK", role=None)` appends one last line `Who: AGK`
   (or `Who: AGK <role>`) after one blank line, unless the body already ends with a `Who:` line (before the runtime's
   footer when one is there); `without_who` takes it off again; `who_fields` and `who_argv` apply `with_who` to the
   `body=` field of a comment write (a POST to `issues/<n>/comments` or a PATCH of `issues/comments/<id>`) and leave
   every other call unchanged.
2. The writers of the four frequent posters pass every comment through it: `session.gh` (`taken:`, `taken over:`,
   `Tell:`, `Slot:`, `Parked-by:`, `Unparked-by:`, `Continued in #n`: `Who: AGK`), `conductor.post` (the light
   re-prove `Report:`, the lease markers, the stall line and `Review:`: `Who: AGK conductor`), `route.write` (the
   `Correction needed:`, `Unreadable:` and `Finished by` comments: `Who: AGK router`) and `merge_cleared.write_once`
   (the record line, the brief and issue notes, the green-again note and the merger's lines: `Who: AGK`). The rare
   posters (`local_mode.py`, `plan_intake.py`, `scorecard.py`, `workflow_apply.py`) are unchanged for now; labels,
   issue bodies, statuses and merge messages are not marked.
3. The texts that sessions copy for their own posts say it once: `.claude/agents/conductor.md` (the shape of a verdict:
   last, `Who: AGK conductor`, which ends all the conductor's comments, `Who: ProductOwner` when relaying the owner;
   the protocol block, shared with the architect, is unchanged, and the messages paragraph and the row 8 lesson are
   said in fewer words with the same meaning, so the file keeps its rule budget of 4496 words and 37 rule lines)
   and `docs/guides/getting-started.md` (`Who posted it.` under item 4 of running the loop, with the builder's
   `Who: AGK builder`). `config/session-rules.md` shows first-line forms only, not whole comments, so it is unchanged.
4. It is a marker, not a rule: no check, guard, router or merge step requires or reads it. Every first line is
   unchanged, so every first-line parser reads a body with the line as without it. The readers that read a whole body
   drop the line first: `session.plain` (a take, a release and a takeover are read from the whole body) and the
   router's `Unreadable:` once-only test, which compares bodies.

## Consequences

Every comment the four scripts post ends with `Who: AGK` (with the role where the script knows it), so the history
tells AGK from the owner at a glance; it costs no call and no turn. A comment the owner types carries nothing, and
nothing asks for it. In CI mode, local mode and personal mode the same scripts post the same footer; no workflow and
no stack's test or build step changes. Tests: `tests/kit/test_who_line.py` (with_who once; the four writers; the
first-line and whole-body readers with and without the line; nothing refuses a body without it), and the existing
post assertions of `tests/kit/` now name the line. Protected path classes changed: `scripts/agk/`
(`scripts/agk/common.py`, `scripts/agk/session.py`, `scripts/agk/conductor.py`, `scripts/agk/route.py`,
`scripts/agk/merge_cleared.py`), `.claude/` (`.claude/agents/conductor.md`), `agk.toml` (the new test file in the `[testing]` map entries of the four
scripts) and `tests/kit/` (`tests/kit/test_who_line.py`
and the post assertions of the existing tests).

## Residual

- 2026-11-14: the rare posters (`local_mode.py`, `plan_intake.py`, `scorecard.py`, `workflow_apply.py`) and the
  builder's runtime task text (`kit/templates/runtime/builder.txt`) do not carry the line yet (brief #1289 answer 1
  leaves them for now).
- 2026-11-14: the steward's relay (SPEC-0059 rule 5) takes the `Who: ProductOwner` form when its builds land.
