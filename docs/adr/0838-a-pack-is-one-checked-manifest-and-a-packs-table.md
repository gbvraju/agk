# ADR-0838: A pack is one checked manifest, listed in a [packs] table, with agk-core built in

- Status: Proposed
- Date: 2026-11-27
- Deciders: maintainers (the owner's yes on brief #2031, 2026-11-27T07:25:55Z)
- Related: ADR-0837, ADR-0804, ADR-0786, ADR-0531, ADR-0639, SPEC-0077, SPEC-0074, REQ-084, brief #2031, plan #661
- Requirements: REQ-084

Protected classes: `scripts/agk/`, `tests/kit/`, `agk.toml`, `kit/`

## Context

SPEC-0077 (Approved, ADR-0837) rule 14 build (a) asks for the pack format of rule 3 and its check, the `[packs]` table of
rule 12 and the built-in pack `agk-core` of rule 2. On main at a43f3976 no pack code existed and `[packs]` in `agk.toml`
was an unknown table. The settings form to copy is `config.steward_settings` and `config.domain_settings`; the check form to
copy is `check_domains.py`, which `check_playbooks.findings` already adds to the `playbooks` step.

## Decision

1. **The format.** A pack is `config/packs/<id>/agk-pack.toml` with rule 3's keys: `format` (1), `id`
   (`^[a-z][a-z0-9-]*$`, never `agk-core`, the folder's name), `version` (exact: `N.N.N` with an optional pre-release,
   never a range), `publisher`, `tier` (`official`, `curated`, `community`), `licence`, `source`, `kit`, `as_of`
   (`YYYY-MM-DD`), `reviewed` (`YYYY-MM-DD by <role or team>`, never an address, `Q-2031-1`), `kinds` (rule 2's nine
   words), `files` (a table of path = SHA-256), `permissions` (a table of `network = "research"` and `mcp = [names]`)
   and the optional `evals`.
2. **The check.** `scripts/agk/check_packs.py` (standard library, `common.py`, `guard`, `playbook_format.source_date`;
   no network, no model) fails each problem as `rule 3: config/packs/<id>: <what> (key: <key>)`, never a value: a
   missing or unknown key, a wrong type (a `bool` is never a number) or value, a kind outside the nine, a file not
   listed, missing or whose SHA-256 differs, a file under no listed kind's folder or outside the pack, an entry of an
   array of tables in a TOML knowledge file with neither a dated `source` nor `basis = "expected"` (`Q-PA-2`), and a
   line that `guard.scan_text` flags. A folder with no manifest, or one that is not TOML, is one line. A folder whose
   name is out of form or flagged is named `config/packs/` only. A pack that `[packs] use` does not list, and a refused
   table, are `rule 12:` lines. `check_playbooks.findings` adds them, so they print as `FAIL playbooks:` lines in the
   existing step; run alone it prints nothing with no pack.
3. **The table.** `config.packs_settings` reads `use` (a list of `{ id, version, sha256 }`, `[]`), `trust` (a tier,
   `curated`), `stale_months` (1 to 60, 12) and `mcp` (names, `[]`). A `use` entry is refused, naming `packs.use`,
   when its keys are not exactly those three strings, its id is out of form, `agk-core` or repeated, its version is
   not exact, its folder has no manifest, the manifest's SHA-256 differs or its `version` differs. An `mcp` name that no
   used pack declares in `permissions.mcp` is refused naming `packs.mcp`. Each refusal is `the [packs] table is refused
   (setting: packs.<key>)`. `packs` is in `config.TABLE_KEYS` and so in `KIT_SETTINGS`.
4. **agk-core.** `check_packs.CORE` is a reserved name with no manifest: the kit's own files where they are today, read
   through `kit_root.kit_file` (`check_packs.core_file`), guarded by the release's `kit/hashes.json` as today
   (`Q-PA-1`). `check_packs.in_use` gives `agk-core` and then the packs of `use`; no reader reads a pack yet (build (b)).
5. **Doctor and uninstall.** `doctor.py` gains `packs-settings` (`ok (<n> packs, trust <tier>)` or the refusal line);
   `uninstall.py` removes `[packs]` through `KIT_SETTINGS` and names `config/packs/` as kept, never deleted.
6. **Wiring.** `kit/manifest.json` lists `check_packs.py` in `verbatim`, because the installed `check_playbooks.py`
   imports it; `kit/hashes.json` is regenerated by `kit_hashes.py`. The `[testing]` map of this repository's `agk.toml`
   names the new tests.

## Consequences

A pack's form, hashes and sources are checked on every governance run, in CI and in `prepush.py`, before any reader uses
it. With no `[packs]` table and no `config/packs/` folder every result is today's. The trust tier, the `kit` range, the
lock, the licence list and the instruction scan are not judged here: builds (c) and (d) add them.

## Residual

`trust` is read and printed but refuses no pack until build (d); `stale_months` warns nothing until build (i).
