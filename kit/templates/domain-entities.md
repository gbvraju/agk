# Entities

The project's domain entities (SPEC-0074 rule 7). One second-level heading per entity, its meaning in one line, then
one list line per relation in the form `relates to <Entity>: <one|many> to <one|many>, <plain reason>`. An entity is
named once and a relation names an entity of this file. `domain_model.py entity` writes them; `check_domains.py`
checks the form.
