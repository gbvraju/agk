# Glossary

The product's own words (SPEC-0073 rule 8): one row per term, with its meaning, the canonical name in code and its
synonyms. It holds only the terms this project uses, at most `[quality] glossary_terms` rows; several names in `In code`
(an adopted codebase's aliases) are one row. A term appears once, never as another row's synonym. The steward's `Term:`
notes in the project's memory stay as they are; this file replaces none of them. `run_gates.py` checks its form.
