- `scripts/agk/lock.py run --name heavy -- <command...>` takes the machine's heavy-step lock, waits its turn (one line a minute naming the holder; `--timeout S` gives up), runs the command without a shell and releases the lock when it ends, also on failure or interrupt; a lock whose process no longer runs on this machine, or older than `lock_stale_minutes` (120 by default), is cleared with a line saying so; `lock.py status` prints the holder or `free`. The local-mode guide uses it instead of its shell snippet (brief #337, ADR-0191 Proposed)
