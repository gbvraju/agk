- A new `[testing] tools_file` (unset by default) names a pinned requirements file that `prepush.py` installs once with the run's interpreter when `[testing] workers` is above 1 and pytest-xdist is not importable, adding `--break-system-packages` only when pip refuses without it; a failed install prints one line naming `testing.tools_file` and the run stays in one process. A full run that takes `parallel_command` with a pytest command at its end gets the same install first. This repository sets it to `config/ci-tools.txt` and gives its compound full command a `parallel_command`, so builder sessions run the full suite in workers as CI does (brief #1021, ADR-0436)
