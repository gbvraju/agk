- A pull request's selected tests now run in the same parallel workers as the full suite: a pytest run whose interpreter imports pytest-xdist gets `-n <workers>` by `[testing] workers`, in CI (`project_tests.py`, `make agk-test`) and in `prepush.py`; without xdist it stays in one process after one line naming `testing.workers`. A selection of at least `[testing] full_when_share` (default 0.5) of the `[proof]` areas' test files runs the full suite instead (`full (selection <n> of <m> files)`). The selected files never change (brief #980, ADR-0419)
