- `scripts/agk/prepush.py` runs, before a push, the fast checks CI would fail on first: the pull request body (`--body FILE`), `make lint` where the project has it, the governance checks that need no network, the secret scan over the branch when gitleaks is installed, and the tests `test_plan.py` selects (`--quick` skips them); it stops at the first failure with its message and prints one timed line per step; a missing gitleaks or `make` is said as `not run` and does not block the push. An optional hook template `kit/templates/pre-push` calls it; the kit never installs it. Session rule 31: a builder runs it before each push; pushing at milestones only is proposed for the maintainers in proposed spec amendments 101 (brief #326, ADR-0186 Proposed)
