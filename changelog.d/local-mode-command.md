- `scripts/agk/local_mode.py enter|leave` lists the workflows to disable or enable and the `gh api` call for each, a dry run until `--write` (refused inside an agent session), which makes the calls and reports a refused one; `leave` takes the start from the open record issue or `--since`, enables only the workflows disabled since then, lists the merges made on local evidence and the catch-up run of each required check on the default branch, or `catch-up: not run yet`, and says to file a priority-0 brief when it is red. The local-mode guide uses it (brief #371, ADR-0213 Proposed)
